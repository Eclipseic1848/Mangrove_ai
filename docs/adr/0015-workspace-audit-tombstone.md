# ADR-0015：工作台删除后保留精简审计记录

状态：已采纳并在批次 8A 落地。

当前工作台任务进入回收站 30 天后会删除任务、版本和事件聚合记录，但下层原始制品、证据
和正式交付继续保留。为兼顾用户界面清理、生产溯源和数据最小化，工作台清理后永久保留
一条不可恢复的精简审计记录：任务与所有者身份、要求哈希或脱敏摘要、来源和结果身份及
哈希、请求格式、终态、稳定错误编号、关键时间和清理原因。

精简审计记录不保存完整用户要求、文件名、业务正文、证据文本、模型回复、凭证、本机路径
或下载链接；它不能恢复任务，也不继续出现在普通用户工作台。工作台“永久删除”不得删除
该记录；未来若要物理擦除审计身份，必须通过单独的数据治理决策和授权流程。
