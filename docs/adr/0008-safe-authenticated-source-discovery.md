# ADR-0008：认证来源发现采用隔离、只读和分阶段确认

- 状态：已采纳，待 Phase 5A 实现
- 日期：2026-07-21
- 决策来源：任务驱动的数据发现、证据抽取与准备蓝图

## 背景

已知 API endpoint 可以由 HttpApiConnector 安全读取，但“登录一个用户有权访问的网站，并寻找目标数据在哪里”需要认证浏览器、站内导航和数据入口发现。网页按钮和网络请求可能产生写入、通知、费用或权限变化；页面内容还可能包含提示注入。账号能够查看数据，也不自动意味着系统可以无限制自动化或批量导出。

## 决策

- 认证来源发现必须在每个用户、每个任务独立的浏览器上下文中执行，不共享 Cookie、缓存、本地存储或页面会话。
- 优先由用户在隔离浏览器中交互式登录；需要代管凭证时，任务只持有服务端 `credential_ref`，运行时临时注入。
- 密码、Cookie、Token、完整授权头不得进入 LLM 上下文、对话、TaskSpec 公共表示、截图说明、日志、Trace、Manifest、错误或下载产物。
- 每个任务必须预先声明允许域名、来源范围、请求/页面/时间上限和只读动作策略；跨域跳转重新校验。
- 默认自动动作仅限导航、展开、只读搜索/筛选/排序/翻页、查看详情、读取现有报表和观察只读网络请求。
- 创建、编辑、保存、删除、发布、发送、审批、导入、退款、权限变更及可能产生费用或业务状态变化的动作默认禁止。
- 如果未来允许副作用操作，必须使用独立能力、最小权限和显式 HITL，不能扩大数据发现任务的默认权限。
- 站内探索先输出候选数据区域、字段和预计范围，用户确认后才批量获取；不得因“营销”“运营”等宽泛目标遍历账号内全部数据。
- 浏览器发现稳定的只读 API 或下载入口后，优先把正式批量读取移交给受控 Connector；浏览器负责发现，不承担可由连接器稳定完成的大规模复制。
- 页面、下载文件和响应均为不可信数据，不能改变系统指令、安全策略、域名范围或凭证处理规则。
- MFA、CAPTCHA、SSO 人工确认或硬件密钥进入用户接管流程，禁止规避。
- 任务完成、取消、失败或超时后销毁浏览器上下文和临时凭证材料。
- 自动化还必须符合用户授权、组织政策、适用条款和法律要求；“账号可见”不是唯一授权判断。

## 后果

- 正面：可以在受控范围内把“未知入口”的授权网站转成可确认、可审计的数据来源发现流程。
- 正面：发现与批量获取解耦，可复用现有 HttpApiConnector、RawArtifact、分页和 checkpoint 能力。
- 代价：需要浏览器隔离、动作分类、凭证服务、会话生命周期、人工接管和网络观察的完整产品链。
- 代价：对 SPA、企业 SSO、Canvas 渲染、反自动化或禁止批量导出的站点不能承诺全自动完成。
- 边界：本 ADR 不授权绕过访问控制、验证码、MFA、网站安全机制或账号权限。
