# ADR-0004：连接器默认只读，禁止写入/DDL/删除

- 状态：已采纳
- 日期：2026-07-19
- 决策来源：plan.md 第 2.3/3/12 节；产品决策（输入权限只读）

## 背景

数据准备平台从互联网、文件、API、数据库取得数据。若连接器可写源系统，存在误改源数据、误删表、误执行 DDL 的风险。

## 决策

- 所有连接器**默认只读**：只获取，不承担写入。
- 数据库连接器要求只读账号；限制单条 SELECT / 受控存储过程；禁止多语句、DDL、DML；设超时、最大行数、批次大小。
- 用户自然语言不得直接拼接 SQL；必须先生成结构化查询计划并经 SQL AST/白名单校验。
- HTTP API 连接器校验协议、DNS、重定向、最终地址；内网 API 用管理员白名单防 SSRF。
- 文件连接器：服务端生成文件名，禁止路径穿越与符号链接逃逸；ZIP 限制文件数/深度/解压比防炸弹。
- Office/PDF 解析不得执行宏、脚本、嵌入对象或外部链接。
- 受控输出目标（MySQL/PG 表写入、S3、HTTP 回调）属 Sink，走 HITL 确认 + 幂等键 + 写入审计，且仅写新产物库。

## 后果

- 正面：源系统零风险；安全测试中写 SQL/路径逃逸/越权下载/明文凭证泄露成功数为 0（plan 15.3）。
- 负面：无法用本平台直接更新源系统数据（非目标场景）。
- 实现：`SourceConnector` 契约只有 probe/discover/read/checkpoint，无 write。
