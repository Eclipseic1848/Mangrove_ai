# ADR-0040：模板与经验的个人范围及通用副本共享

- 状态：accepted
- 日期：2026-09-07
- 决策来源：用户确认；Issue #117
- 关联：ADR-0037、CONTEXT.md 的 TaskTemplate、OwnerMemory 和 AuditView

## 决策

任务自动蒸馏的报告模板与失败经验默认归原 Owner，仅在本人范围内生产、去重、召回和使用。
保留现有评分、晋级和淘汰，不因质量通过或转正自动获得跨用户共享权限。

Owner 可预览并编辑通用副本，明确确认已移除个人信息、凭据和业务专属内容后共享给平台用户。
确认绑定实际 Owner、来源内容摘要、确切副本内容摘要和时间；模型通用化提示不能代替授权。
平台副本与个人原件独立，源内容更新不能自动改变已经确认的共享正文。重新分享不同内容需重新确认。
作者可撤回共享副本；管理员可管理平台副本，但不能据角色直接读写他人的个人原件。

平台副本独立累计使用效果并沿用现有质量生命周期。报告模板草稿仍可试用并达标转正；经验
仅允许已转正的个人来源贡献，其平台副本保留来源质量依据、从零累计平台使用效果。
本人经验达到原有重复发生次数后允许本人试用，从真实后续成功中累计有效次数，再由原有条件转正；
平台经验保持已转正召回门。不得通过测试直接写状态来冒充实际晋级链已经运行。

未知归属或缺少确认依据的历史条目保留原件，不自动认领、公开、进入模型输入或巡检删除。
历史库存认定、生产迁移和批量发布需独立执行与验收，本决定不授权这些动作。

## 边界

本决定针对旧报告模板和失败经验文件库。版本化 TaskTemplate 仍只是可见任务草案，OwnerMemory
中的个人偏好、事实不能因此共享；能力包的签名、验证、admin_gray 发布与受众门也保持独立。

管理列表、统计和巡检摘要只提供允许的元数据。跨 Owner 业务正文需明确原因与不可变审计，
不提供批量正文导出，不将原始工具日志、Secret 或宿主路径当作审计正文公开。

## 后果

不新增评分系统、候选库或通用审批框架。共享增加一次预览确认；旧自动派生内容不再默认
全局可见。工程验收须覆盖页面、API、模型召回、融合、质量统计、撤回以及未知历史条目保留。
