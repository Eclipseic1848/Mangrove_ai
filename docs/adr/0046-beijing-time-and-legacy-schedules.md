# ADR-0046：北京时间与历史计划保护

- 状态：accepted
- 决策来源：用户确认系统统一北京时间，历史无时区记录保留原值并明确标注。
- 替代范围：ADR-0045 第 2 条的服务器本地时区约定及旧计划自动执行语义，其余授权、模型冻结和通知边界不变。

## 决策

1. 新计划固定按 Asia/Shanghai 定义触发时间；新业务时间携带偏移，界面统一展示北京时间，不依赖浏览器或服务器所在时区。
2. 历史无时区记录不猜测、不批量换算，保留原值并标注“历史时区未记录”。缺少时区的旧计划不自动补跑，用户核对时间和模型后明确重新创建，旧记录保留。
3. 停止状态未知的计划不得通过重建入口绕开禁止重复执行的保护；须先确认执行已停止。
4. 迁移仅增加所需字段，原库需备份、验证再切换；内部 UTC 协议、凭据时效和不可变历史不因展示约定而重写。
