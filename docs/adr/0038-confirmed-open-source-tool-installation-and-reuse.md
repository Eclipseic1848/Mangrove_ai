# ADR-0038：开源工具采用确认安装与持久复用

- 状态：`accepted`，用户于 2026-08-30 明确确认
- 日期：2026-08-30
- 决策来源：GitHub Issue #87
- 关联：ADR-0026、ADR-0028、ADR-0029、ADR-0036

## 背景

Mangrove 已用 `gray-python-table` 和 `gray-everything-mcp` 验证能力包、Sidecar、供应链和生命周期
治理，但它们分别只是窄表格汇总工具和 MCP 协议测试服务，不是用户需要的平台产品能力。

用户期望的体验接近成熟编码智能体：任务先使用已安装工具；缺少能力时从可信开源来源发现
Tool、MCP 或 Skill，说明用途、来源和权限，经一次确认后安装并在以后相似任务中复用。用户不需要
看到个人能力晋级为平台能力的复杂流程，也不希望 Mangrove 为常规任务重复造轮子。

## 决策

### 1. 产品流程只有发现、确认、安装和复用

任务先查询现有 CapabilityCatalog。缺少合适能力时，系统可以搜索配置的插件目录、代码托管站、
MCP 目录或包仓库，并展示候选工具的用途、发布者、来源、精确版本、制品 digest、许可证、所需
权限和数据外发范围。用户确认后才安装；未确认不得下载、执行或授权。

安装记录和精确制品持久保存。后续相似任务优先复用已安装版本，不重复搜索或下载。上游更新不
自动替换已安装版本；升级是新的确认动作。工具运行本身需要联网时，仍按其冻结的外发范围执行。

Mangrove 继续复用现有 CapabilityPack、CapabilityCatalog、CapabilityHost、供应链检查和隔离能力
作为内部安全机制，不另建一套插件系统，也不在普通用户界面暴露成熟度、晋级、快照签名等治理
术语。

### 2. 安装范围只有个人和平台

- 个人工具由普通用户确认安装，仅该 Owner 可选择；
- 平台工具只由管理员安装，可供平台用户选择；
- 相同制品可以按 digest 复用存储，但 Cookie、API Key、连接配置、授权和业务数据始终按 Owner
  隔离；
- 普通用户不能把个人工具直接共享或提升为平台工具。

平台工具的安装仍须满足现有来源、供应链、沙箱和运行门。该内部检查不等于让用户参与一套能力
发布流程。

### 3. 不把任务代码自动沉淀为工具

智能体为当前任务生成的脚本或代码只属于该任务，不能因为一次成功就自动注册为持久工具。
只有用户以后明确要求产品化，才另行规格化、测试和安装。默认优先选择已有成熟开源工具。

`gray-python-table` 和 `gray-everything-mcp` 继续作为内部回归夹具，不进入普通用户工具目录。
本决策不删除它们的源码、治理证据或测试；后续只有在等价回归覆盖就位后才能单独清理。

### 4. 数据外发按任务范围确认

- 已安装且完全本地运行的工具不重复确认；
- 只处理公开网页的外部 MCP/API，在任务开始时明确展示工具和目标，不逐次弹窗；
- 向外部服务发送用户文件、私有数据或登录后内容，必须按 TaskRevision 在开始前确认一次；
- 同一任务、同一服务和同一数据类别不重复确认；服务、权限或数据类别扩大时重新确认。

### 5. 只统计模型 Token 和可选参考费用

平台只按 Owner、模型连接、密钥版本、模型、任务和 WorkSession 汇总 Provider 返回的输入、输出和
总 Token。用户自带 API Key 与平台连接使用同一口径，只展示连接名称或不可逆指纹，绝不展示
密钥明文。

只有取得匹配 Provider、模型和时间的官方价格时，才显示带来源与时间戳的参考费用；缺失价格或
Token 时显示未知，参考费用不是账单。工具仅记录调用次数、耗时和结果状态，不建立工具费用、
套餐或产品配额系统；现有运行时资源和安全限制继续生效。

### 6. 工具失效时直接说明并允许继续原任务

工具不可用、被禁用或不再满足安全门时，当前调用停止并明确显示原因。系统可以推荐替代工具；
用户确认安装后继续原任务，不静默替换。替代工具若扩大权限或数据外发范围，必须重新确认。
版本、Run 和恢复记录由后台保留，不把内部状态机暴露给用户。

## 拒绝的替代方案

- **让每次任务都重新搜索和下载**：慢且无法复现，拒绝。
- **自动安装或自动升级开源工具**：绕过来源、权限和供应链确认，拒绝。
- **把一次任务代码自动晋级成平台工具**：扩大维护和安全范围，拒绝。
- **把内部能力晋级流程做成普通用户产品流程**：不符合用户需求，拒绝。
- **为工具建立费用、套餐和复杂配额**：当前只需要模型 Token 与参考费用，拒绝。
- **工具失效后静默换用替代品**：可能改变权限、外发和结果语义，拒绝。

## 后果与完成门

P1 实现必须证明：缺失工具时能够展示候选并等待确认；安装后原任务可继续；下一次相似任务直接
复用同一精确版本；个人工具不能被其他 Owner 使用；平台工具可复用代码但仍使用各 Owner 自己的
凭证；工具禁用后不再调用且可经确认替换；私有数据外发会触发任务级确认；平台密钥和用户自带
密钥都能汇总 Token，并仅在官方价格可用时显示参考费用。

普通用户目录不得把两个灰度回归夹具当作产品工具。本 ADR 不安装任何第三方工具，不授权真实
外发、Secret 配置、生产数据访问、公开发布或删除既有资产。
