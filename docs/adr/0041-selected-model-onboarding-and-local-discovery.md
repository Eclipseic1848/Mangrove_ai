# ADR-0041：先验证所选模型，本地发现与推理分开

- 状态：accepted，实施与真实验收由 #159 跟踪
- 日期：2026-09-07
- 工单：[云端与本地模型配置 #159](https://github.com/Eclipseic1848/Mangrove_ai/issues/159)

## 决策

1. 创建个人或平台预设连接，默认只发送一次所选模型的合成文本测试。所选模型失败不保存、不换型号。其余目录型号保存为未启用的 `pending_validation`，用户以后可逐项验证。显式批量接口保留，但不作为普通配置流程。
2. 模型列表读取默认只 GET 指定服务的 `/models`，不推理、不授资格。四协议探测仅在高级入口明确告知测试用量后执行。不支持列表可手填；鉴权、网络、限流与重定向错误须分别说明。
3. 地域与业务空间只能填入平台维护的可信端点模板。切换服务商或地域清除原密钥，不猜测密钥所属站点。新目录不改旧连接与冻结任务；重验只接受该连接已有的型号，并使用持久化端点及协议。
4. 本地服务复用管理员的 managed-private 连接边界；普通用户可找到入口并获知管理员登记路径。只对模型 Broker 显式启用精确 `localhost`、`127.0.0.1`、`::1`，且解析结果必须全为回环。通用 HTTP Guard 仍默认拒绝回环；元数据、重定向和 DNS 混合解析继续拒绝。
5. localhost 指 Mangrove 后端所在环境。用户只接入已启动的模型 API，不扫描设备、不下载模型、不安装运行时、不修改防火墙或监听范围。无鉴权本地服务无需虚构 Key。
6. 目录核验、连接保存、文本测试和工具调用资格分别呈现。未知请求结果不得自动重发；Owner、Vault、账户停用、Grant、任务冻结及外发边界沿用现有实现。

## 取代范围

取代 ADR-0022 第 3 条的默认批量验证与第 5 条创建时自动改选；保留逐模型状态、显式默认选择和历史冻结。取代 ADR-0024 第 6 条默认四协议探测，仅高级明确操作保留该能力。其他决策不变。

## 验证边界

隔离 HTTP 协议测试与浏览器模拟不证明真实账号或本地服务可用。真实调用需具体授权，证据与同提交 CI 均完成后才能关闭 #159。#127 承接原任务返回与输入旁选模。
