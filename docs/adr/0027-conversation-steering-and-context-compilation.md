# ADR-0027：任务对话采用不可变原话、语义转写与 Revision 差异门

- 状态：`accepted`，用户于 2026-08-02 逐项确认
- 日期：2026-08-02
- 决策来源：[Agentic 能力获取、SOP 与对话上下文规格](../plans/2026-08-02-agentic-capability-sop-context-spec.md)
- 上游：[ADR-0017](0017-agentic-runtime-vnext.md)、[ADR-0018](0018-unified-task-domain-contract.md)

## 背景

当前工作台允许在终态任务底部追加修改，后端把旧 `objective_text` 与“用户修改要求”直接
拼接；运行中创建新版本会先取消当前任务。待回答问题只有 `answer` 入口，尚不能区分状态
询问、依据追问、无实质变化的口语转写、结果修改和独立新目标。继续把完整聊天历史追加到
Prompt 会浪费上下文，也可能让一次状态询问意外改写当前任务。

用户需要在任务执行期间持续追问，并希望 LLM 把不专业、指代模糊或重复的表达转写为更
适合执行的上下文；但 LLM 不能把润色后的文本冒充用户原话，也不能自行批准业务范围、数据
含义、权限、外发或不可逆操作变化。

## 决策

1. 每条用户输入先保存为不可变 `RawUserTurn`。LLM 只能基于原话和已确认上下文生成带来源
   回合、置信状态和开放问题的 `ContextDelta`，不得覆盖原话。
2. `ConversationSteering` Module 对外只返回五类结果：即时回答、无实质变化的自动转写、
   待确认任务修订、建议新任务或权限/外发请求。状态与依据追问不改变当前 Run。
3. `SemanticDiffGate` 确定性检查 ContextDelta。改变来源范围、字段/计算含义、结果基数、
   输出语义、权限、外发或不可逆动作时，只能生成待确认 revision 草案；高置信度且不改变
   业务结果的口语规范化可以自动应用，并显示“我理解为”和纠正入口。
4. 用户确认实质变化后创建不可变 `TaskRevision`。运行中的原子操作在安全点结束；用户可以
   选择立即取消、完成当前步骤后切换，或创建独立任务。不得在工具写入中途修改冻结目标。
5. `ContextCompilation` Module 按权限边界、冻结 GoalContract、已确认数据含义、当前状态、
   相关对话、能力/方案摘要和按需 EvidenceRef 编译有界 `CompiledContext`。完整聊天、OCR
   全文、控制台日志和重复 SOP 不默认进入模型窗口。
6. 原话、TaskRevision、事件、制品和证据是权威记录；CompiledContext 只是一次模型调用的
   可重建视图。压缩不得丢失确认过的范围、字段含义、权限、外发、失败关闭和开放问题。
7. 执行进度以持久化结构化事件流展示，不流式暴露模型原始思考。对话内保留一张持续更新的
   紧凑任务卡，展开后显示时间、行动、依据、真实进度、能力/方案选择、重规划和可执行操作。
8. 只有存在真实分母时显示百分比。普通用户看到任务语言，管理员可以查看来源、版本、哈希、
   权限和技术证据；两类界面都禁止 Emoji，并在刷新或 SSE 重连后恢复唯一活动状态。
9. 对话输入框在任务运行时保持可用。每次追问必须明确反馈“已回答且不影响任务”“已生成
   revision 草案”或“建议创建新任务”，不能把消息静默吞入 Agent 上下文。

## 考虑过的替代方案

- **完整聊天历史直接拼接**：实现简单，但上下文无限增长且旧语义会污染当前 revision，拒绝。
- **只保存转写后的 Prompt**：无法追溯 LLM 是否改变用户含义，拒绝。
- **每条追问都创建 revision**：状态询问和依据追问会导致无意义取消与重跑，拒绝。
- **允许 LLM 直接更新当前任务**：绕过人工控制的业务与权限边界，拒绝。
- **流式展示原始思考**：噪声大、不可审计且可能暴露敏感或已推翻假设，拒绝。

## 后果

- 需要独立保存用户回合、ContextDelta、revision 草案和编译上下文引用，并把现有字符串拼接
  修改入口替换为可恢复的 ConversationSteering Interface。
- LLM 仍负责理解非标准表达，确定性代码只守住语义差异和权限门，不退化为关键词路由。
- 前端事件将从固定阶段摘要升级为“阶段 + 结构化事件 + 受众投影”，同时保持旧事件可忽略。
- 本 ADR 不授权更改现有任务数据、默认入口、模型外发、提交、推送或外部发布。
