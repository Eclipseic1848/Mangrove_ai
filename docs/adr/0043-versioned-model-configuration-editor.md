# ADR-0043：模型配置统一维护与追加版本

- 状态：accepted
- 日期：2026-09-15
- 决策来源：用户确认模型与连接、平台配置归一方案，并授权备份迁移与重启。

## 决策

1. 模型日常维护只在“模型与连接”呈现。本地与云端两类；云端按供应商组织。
   平台配置保留跳转入口，不再展示旧模型参数编辑。后台旧参数和兼容读取保留，
   不删除、不宣称旧任务已经迁移到新连接。
2. 编辑现有连接时先验证精确草稿，再保存；API Key 留空表示保留，原值不返回前端。
   更换地址须明确确认向新地址发送验证请求与密钥。个人仅管理自己的连接，管理角色可管理共享连接。
3. 保存追加替代连接及秘密版本，不覆盖旧记录。历史冻结任务仍可使用旧版本；被替代版本退出
   新任务目录，旧默认偏好保持身份但标为不可用，用户需重选，不静默替换。
4. 验证由 actor 与 operation ID 幂等绑定；重复提交及只读核对不重复调用 Provider。
   未知结果不自动重试，浏览器只保存操作 ID，恢复时读取非秘密草稿；用户核对用量后可显式重新编辑。
5. 本地 Qwen Chat 支持默认、开启、关闭思考。验证和 Relay 使用同一配置，调用方明确的
   结构化输出选项优先于连接默认。其他接口不假装支持该开关。
6. 新增 webui_0019，只有显式备份迁移可建表。版本链连接不能物理删除，仍可显式停用撤销授权。

## 兼容边界

本决策补充 ADR-0022/0023 的配置更新路径，不改变既有任务的外发确认和 Purpose Grant。
旧流程参数仍是其服务器兼容配置；统一的是当前产品维护入口，不是无条件重写所有旧运行路由。
合成验证不等于真实供应商验收。本次不更换现有密钥，不重新验证真实模型。
