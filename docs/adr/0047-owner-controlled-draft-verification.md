# ADR-0047：初稿生成后由用户决定是否继续核对

- 状态：accepted
- 日期：2026-09-20
- 决策来源：用户要求初稿生成后默认暂停，不再默认继续核对。
- 替代 ADR-0042 第 2 条的默认自动验证行为，其余接受与发布安全边界不变。

## 决策

1. 工作台 Pi 执行形成完整、可重开的初稿文件集合后，冻结文件并结束本轮执行，释放运行资源，持久保存为等待用户决定。不是正式交付，也不表示准确性已验证。
2. 用户可查看、下载并选择接受初稿；接受仍走 ADR-0042 的 OwnerAcceptance 和唯一 Publisher，不再调用模型核对，不豁免文件 QA、Owner、来源、取消及版本约束。
3. 只有用户明确选择“继续核对”，才恢复原 TaskRevision、Run 和会话。批准绑定精确初稿与运行身份；缺少恢复会话时拒绝恢复，不偷偷重做任务。
4. 未批准的等待状态不进入启动恢复队列；已批准的排队状态与决定一起保存。重复点击、取消、旧版本和跨 Owner 请求不能扩大执行权限。
5. 不新增 Schema 或依赖；复用任务问题快照保存决定。已发送至模型的请求仍可能产生已发生用量，不承诺撤回外部提供方的在途计算。

## 边界

仅作用于工作台 Pi 初稿链路；没有初稿能力的运行路线不伪造暂停状态。任务的新要求仍经过既有修改确认和新版本流程。“继续核对”不代表用户接受结果，也不授权新增来源、模型或对外发送。
