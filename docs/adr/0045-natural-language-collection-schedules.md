# ADR-0045：自然语言创建采集类定时任务

- 状态：accepted
- 日期：2026-09-17
- 决策来源：用户确认定时需求应由工作台自然语言识别并自动创建，而非跳转配置引导。

## 决策

1. 明确的用户定时执行要求是创建授权；缺少时间或周期时追问，不猜测。咨询、引用、否定和
   助手回复不形成创建授权。继续使用已有 Conductor 采集类调度，不新建通用任务调度引擎。
2. 宿主复用计划解析、Owner 校验和一次性动作领取创建计划；成功持久化后才展示创建回执。
   同一工作台请求不重复创建，失败或结果未知不自动重试。时间按服务器本地时区执行并在回执说明。
3. 新计划保存用户原始要求与冻结模型连接版本；执行时复用连接授权，连接失效必须停止。
   不从当前默认模型补绑旧计划，不允许通过旧模型编辑字段绕过冻结连接。
4. 明确要求结果邮件的定时计划复用 ADR-0044 的通知出口；只在本次结果明确通过质量检查时
   自动发送业务文件。缺失检查、检查失败、投递未知都不能冒充成功；保留报告与发送提示。

## 范围与兼容

保留既有计划、运行记录与旧计划执行语义。上传文件任务的周期执行需要独立的来源冻结与
任务执行适配，此决策不代表该能力已实现。隔离模型与邮件测试不等于真实供应商验收。
