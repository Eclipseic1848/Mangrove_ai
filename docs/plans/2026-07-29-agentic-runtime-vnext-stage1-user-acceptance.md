# Mangrove Agentic Runtime vNext 阶段 1 用户验收说明

> 本次验收不是确认某个框架已经可用于生产，而是确认没有候选可以不加生产控制直接上线。
> 后续 Pi 全能力生产灰度决策见文末。

## 1. 最省事的验收方法

打开
[阶段 1 执行报告](2026-07-29-agentic-runtime-vnext-stage1-execution-report.md)，
依次确认：

1. 三个候选都使用本地 `Qwen3.6-35B-A3B`；
2. Pi、OpenCode、Deep Agents 分别为 16/18、16/18、12/18；
3. 每个候选至少有一项核心用例没有连续三次通过；
4. 报告没有把 88.9% 写成生产合格，也没有宣布相对领先者胜出；
5. Legacy 默认入口、生产数据库和正式 Delivery 都没有被修改；
6. 报告明确列出尚未验证的真实解析、长上下文、恢复、泛化集和生产隔离范围。

以上六项均符合，即可认可本阶段的“无胜出候选”结论。

## 2. 可选的本机查看

不需要重新安装或运行 54 次。若想亲自看一次过程，在项目根目录执行：

```powershell
.\evals\agentic-runtime-vnext\run.ps1
```

界面操作：

- 按 `1` 选择 Deep Agents，`2` 选择 OpenCode，`3` 选择 Pi；
- 按 `c` 切换冻结用例；
- 按 `r` 运行；
- 按 `q` 退出。

重点看五项：

- 首个工具是否为“观察来源”；
- 是否只读取目标契约允许的来源；
- 工具失败后是否更换目标，而不是重复空转；
- 模糊目标是否提供真实选项并停止；
- 最终只生成候选，并由独立 Verifier 判断通过或失败。

运行记录只写入 Git 已忽略的 `runs/`，不会成为正式下载，也不会改生产数据。

## 3. 你需要做的唯一决策

请确认是否接受以下推荐：

> 三个候选均不直接替换 Legacy；本页当时建议按 ADR-0017 设计和实现最小
> Mangrove-owned Kernel，并在独立验证通过前只允许管理员灰度。

确认后才进入阶段 2。未确认前，不会修改生产 Runtime、数据库、前端入口或发布设置。
