# #127 统一工作台任务单

## 目标
按已认可 #124 原型，把 /data-prep 变为统一自然语言入口；输入旁选模，文件自动侧览，窄屏可达；保持正式交付语义与旧能力。

## 允许输入
#127正文、#124已认可规格/原型、当前TaskComposer/SemanticWorkspacePage/Layout、#159连接面板、#125冻结契约、#126制品契约、现有上传和预览组件。只用合成验收文件。新增依赖另行确认。

## 要求输出
一个主任务导航；统一输入承接已接通能力；常驻模型选择与添加配置返回；文件预览打开时对话同列收窄；历史/刷新任务身份；同步DESIGN与现有tokens。

## 验收标准
CSV/Excel/PDF/Word既有能力保留矩阵；QA和output_id真实交付；1440/390/短屏、明暗、IME、键盘、reduced-motion、历史前后退；两轴审查与同提交门。未接通联网/混合不能假开放。

## 边界
#159完成后才开始产品修改；不新worktree、不动CoreMind专属checkout、生产数据或秘密、既有服务和4190原型；不删/chat或legacy有效能力；不把候选当正式交付。

## 交互实现约定

以已认可 #124 原型为依据，保持现有颜色和字体，精准同步 DESIGN 的布局与导航。Radix Dialog 管抽屉；原生 select 管选模；既有 ModelConnectionsPanel 管配置，输入组件保持挂载，正文不为跨页恢复新写浏览器持久存储。对话历史读取已有 Owner 受控 turns 接口，不能在浏览器伪造过去消息。

网页入口接受主输入的要求和明确模型，仍走既有精确网址/范围/用途/外发确认；未接通网页与文件混合、全网搜索不创建假任务。旧入口仍可访问。输入页隐藏引擎选择，实际路由由既有平台默认策略冻结，UI 不自动切换运行时。

## 验证状态

本文件是任务单，不宣称完成。工程、模拟浏览器、真实合成文件链、用户视觉认可、生产资格分别记录。前端设计由用户指定 Astra high，普通审查按 Astra low；实际 turn_context 单独核验。
