# #132 完整来源导出

## 目标、输入与输出

复用冻结 TaskRevision、SourceSnapshot、上传原件与正式 Delivery，提供普通用户可下载的完整资料包，不建设另一套采集或数据存储。

输入仅为当前 Owner 在所选任务修订中冻结的来源。输出包含原件字节、Markdown 人读表示、JSON/JSONL 结构表示及逐文件 SHA256、大小、记录数清单；可选 CSV/XLSX 为表格投影。来源 URL、最终 URL、读取时间、快照身份、解析版本与缺口分开记录。原始来源和正式结果不混称。

## 接缝与交互

- `GET /api/semantic-workspace/tasks/{task_id}/source-bundle`，必填 `revision`，可选 `artifact_id`，`table_format=none|csv|xlsx`，返回 ZIP；不要求已有正式交付，但来源必须已冻结且可用。
- 原结果 `bundle?include_sources=true` 复用相同来源写入与校验，继承正式输出 QA、修订和完整性门。
- 现有来源侧栏提供“下载完整资料包”，默认包含原件、Markdown、JSON/JSONL，可选表格格式。切换任务/修订、关闭或取消后不能触发迟到下载；错误保留当前任务与重试入口。
- 4000 字网页预览继续明确为预览；资料包从已保存字节生成，不能复用截断预览冒充原文。

## 边界

- 导出不采集、不联网、不调用模型或 OCR。图片/扫描页没有可用解析时保留原件并明确缺口，不补造全文。可安全复用的本地解析器负责离线表示。
- 原件分块写入并校验；派生只从本次已校验原件读取，不能被校验后的源文件变化替换。解析上限、容器展开和表格投影上限如实列入缺口，不静默截断或删除原始资料。
- JSON 为类型和空值的结构依据；重复键、数值精度变化或部分解析失败必须明确标记，原件保留。CSV/XLSX 投影不能冒称原始无损数据，沿用既有防公式策略。
- 链接与未抓取附件只登记未保存；Markdown 不嵌入外部图片/脚本。运行秘密、宿主路径及内部服务响应不进入公开元数据。
- 跨 Owner、所选修订不包含来源、冻结身份/摘要变化、不可用来源失败关闭。存储不足限制本次导出并提示；异常、取消、断连均只清理本次临时资料包。
- 不新增依赖、生产迁移、公开部署或真实业务数据验收。所有前端任务 Astra high，其余委派 Astra low；主会话 Astra medium。

## 验收

1. 超过 4000 字中文原文、分页来源、链接、类型/空值、多文件和部分解析失败，可从包内原件和清单核对；同快照重导出零网络。
2. HTTP 覆盖无正式交付、历史修订、Owner/来源成员拒绝、哈希漂移、存储失败和临时包取消清理；既有正式结果包兼容。
3. 浏览器覆盖格式选择、等待/重复点击、失败恢复、取消/迟到、修订切换、明暗主题及窄屏；保留原有结果下载。
4. 永久失败回归、受影响兄弟路径、独立 Standards/Spec 与最终同提交 CI 通过后，按既有授权合并并关闭。测试与生产/用户验收资格分别记录。
