# #134 无网址公开搜索

## 目标与允许输入

用户在统一工作台输入需求，明确选择公开搜索后，在给定主题、时间筛选和有界站点范围内发现链接、读取正文，并沿既有来源快照、任务修订、所选执行器和交付流程回答。无需预先提供网址。

允许输入为当前 Owner、幂等键、公开查询（最多 500 字）、用途、可选时间筛选与最多 10 个域名。公开搜索默认读取最多 10 个候选页面，最高 20 个；单网址与同站模式维持既有边界。网址与查询二选一。只有明确的搜索动作将查询发送给固定公开搜索服务，不发送上传文件、业务正文、凭据或模型密钥。

## 要求输出

- 来源获取记录保存冻结查询、时间、域名、Provider 身份与候选链接；报告区分发现、实际读取、失败及越范围拒绝。搜索摘要不能冒充原文。
- 取得正文后继续生成既有 SourceSnapshot 和 Artifact，原始字节、摘要、读取时间及 Owner 绑定保持；任务创建后沿原文资料包下载保留原文。
- 零结果、搜索阻断、超时、未知页面结构、正文读取失败分别解释。9/10 保留取得的 9 页和缺口；硬性最低页数未满足时不绕过原启动门。
- 达到页面目标只说明此次有界读取满足数量，不证明全网完整、内容真实或每页发布时间已独立核验。
- 取消和幂等重放复用现有执行身份；取消后不继续正文请求或接受迟到结果。网页中的指令不改变冻结权限、模型或来源范围。

## 最小实现

沿现有 source-acquisitions API/Service/Repository 扩展 public_search 模式，不另建搜索任务系统。现存 DDGS 的同步客户端、环境代理和后端回退不符合项目网络边界，因此只采用固定公开搜索页面的有界发现接缝，复用已安装解析依赖；网络仍由现有 HTTP 安全检查与固定 IP 传输负责。正文复用 AnonymousWebFetcher，不无限跟链。

搜索结果单独存入 attempt 的 search_report_json；显式 webui_0015 迁移只增加此列并更新结构冻结。搜索失败或零结果不制造空 SourceSnapshot，仍可恢复查看报告。来源正文继续使用原有不可变表，不复制另一份内容存储。

## 验收标准

1. 公开 API：只提供查询到达现有来源流程；网址历史请求兼容；混合、超界和错误范围在联网前拒绝。
2. 来源服务：固定合成查询得到跨站候选、真实合成 HTTP 正文与快照；普通重放无重复搜索/读取；其他 Owner 无法取得记录或原文。
3. 网络与失败：逐 URL 的 SSRF/重定向限制，搜索反爬与零结果区分，部分读取失败保留成功页；取消迟到与关闭验证。
4. 用户旅程：无附件无网址需求可明确搜索，等待/恢复/取消状态可理解；候选和已读来源分开，已有原文下载路径可达；文件和网址旅程不退化。
5. 独立 Standards 与 Spec 审查、受影响回归、最终同提交 CI。真实匿名站点探针单列结果，不用合成响应冒充搜索服务可达或真实模型质量。

## 边界

不新增依赖，不自动安装工具，不启用 Agent-Reach 或其他待批准适配，不访问认证网站、不绕验证、不调用收费搜索后端。不扩大平台包受众、不切换冻结执行器，不操作生产数据库、现存服务或其他工作区。真实登录由后续 #138 通用能力承接；当前遇到需登录的来源只解释并等待用户决定。
