# 模板、教训与巡检：工作台自动复用补齐

状态：已完成本机工程集成与显式迁移，待用户验收；自动巡检经用户确认保持关闭。最新验证与部署事实以 `docs/status/current.md` 为准，下文隔离阶段待办是实施时记录，不代表仍未部署；不宣称真实模型效果已经验收。

## 已确认边界

- 用户自然语言描述任务，不增加必选模板或配置步骤。
- 当前用户要求、冻结任务目标、来源、输出格式及授权优先于经验建议。
- 涵盖模板库、教训库、巡检报告；普通用户、管理员、超级管理员均核验。
- 个人内容按 Owner 隔离；平台共享沿用 ADR-0040 的本人确认副本。管理角色不直接获得他人个人正文。
- 用户明确保留现有巡检自动删除策略：合并删除重复条目、清理符合条件的超期草稿；不改为归档。未知归属历史仍不认领、不召回、不清理。
- 隔离数据库、文件目录和模拟模型验证；不执行真实任务、真实巡检或历史数据改写。
- 收尾审查以本轮开工源码副本为基线，不混入此前未提交功能。
- 用户已授权独立学习回执表的显式迁移，前提是源码与原库备份、隔离迁移与恢复验证通过；当前尚未执行原库迁移，不改写已有任务、模板或教训。

## 实施顺序与完成门

1. **库读取与权限基线**：单条异常数据不使列表、召回或巡检全量失败；原文件保留；三角色隔离与共享撤回回归。
2. **自动方法建议适配**：复用当前冻结上下文接缝。记录命中的确切来源与内容摘要，用户目标/格式不被覆盖；不把旧报告提示直接当作可执行清洗脚本。类型不适配、无可靠匹配、权限不符时不用模板。
3. **完成反馈与学习**：按各链路已有完成门沉淀。新工作台必须使用独立验证及正式交付证据；接受初稿不能冒充 QA 通过。记录必须绑定 Owner、Task、Revision、Run，重试/重开历史不得重复累计。失败只学习已观察到的失败，不生成无依据的教训。
4. **管理页面与联动验收**：三 Tab 清楚展示用途、范围、状态及实际使用效果；验证新任务、失败恢复、历史重开、巡检与三角色页面/接口/模型输入一致。

## 实施限制

- 现有版本化 TaskTemplate 与旧分析模板不是同一种资产。自动复用只能作为可追溯的方法建议；可执行 Procedure 仍遵循 ADR-0026 等能力治理，不通过文件模板绕过验证与发布。
- 旧 DataType 面向采集内容，不能用 generic 统一冒充文档解析、表格治理的适用类型。
- 当前仅证明显式上下文路径和旧学习路径的工程行为；不能据此宣称全工作台自动学习已完成。
- 前端已在隔离副本补齐展示与错误状态，真实运行版本尚未切换；定点页面验证不代表整个学习功能已交付，验证结果与后续状态统一记录在 `docs/status/current.md`。
- 自动召回子片复用旧库的本地关键词匹配，并要求明确的 workspace_document/table/web/mixed/file 类型；不额外向 embedding 或模型服务发送创建请求内容。旧采集类型保持原逻辑，未重新分类或改写历史条目。
- 自动建议冻结精确版本，仅提供方法；同目标与格式的重试继承冻结快照，目标或格式改变时不继承旧自动建议。学习回执部署、旧直连方法沉淀与教训接线仍待完成。
- 用户已确认：新工作台方法先存草稿并自动试用，达到现有最少使用次数且这些使用均通过独立验证后自动转正；接受初稿不计成功，存在未验证使用时不自动转正。新工作台没有旧报告质量分，不得用 passed 伪造 100 分；旧报告现有评分与晋级规则不变，转正不扩大共享权限。
- 新方法草稿由已验证的冻结目标、输出格式及核验项目提炼，明确是待试用建议，不声称已还原真实执行步骤；不把生成它的任务算作试用成功。只调用原 Owner/Revision/Run 的冻结模型连接，用量沿现有 Broker 账本保存。生成中断或响应未知不自动重发；已有方法命中时不重复生成；本地去重不引入额外向量或裁决调用。教训因果与有效性接线仍未完成。
- 教训本地召回沿用本人重复草稿试用、已转正平台副本门，严格匹配 workspace 来源类型，最多三条。冻结独立内容摘要，控制语句及凭据条目不注入；不把提醒写成已发生事实，不增加有效次数。新任务冻结前重新检查可见性/状态/内容，历史快照不因原件删除而改写；旧上下文无 lessons 时默认空值，未改写旧记录。
- 失败学习只采纳明确业务失败项，排除无结论与可能由连接、读取故障造成的检查。失败事件先于任务终态保存学习意图，后台恢复并持有原任务授权；文件更新绑定本次执行及报告摘要，报告变化拒绝重放。新文件写入中断后若原件缺失，不擅自重建；保留原有删除策略。有效性计数仍未接线，不从偶然成功推断建议有效。
- 用户确认有效性口径：本次实际采用教训、独立检查对应风险通过、正式交付，三者齐备才累计。独立验证只评估冻结且实际纳入上下文的教训；引用须来自模型可见的候选正文和已核实来源正文。单纯成功、建议已提供或执行器自称采用都不算证据；过程性建议无法由现有材料验证时不计数，不新增用户配置。证据核验子片已在隔离实现；正式交付后的逐教训幂等更新尚未接线。
- 2026-09-19 用户确认本地直连兼容边界：历史任务不补学，新建任务使用本次执行冻结模型/端点与学习用量记录，不增加用户配置。复用现有执行快照、创建事件和用量事件，不另建连接表；请求前登记未知、返回后关联同一次调用，不把进程中断伪装成零消耗。正式交付方法草稿及明确业务失败教训路径已隔离实现；无结论、基础设施失败继续拒绝生成，最终现状与验证证据以 current.md 为准。
