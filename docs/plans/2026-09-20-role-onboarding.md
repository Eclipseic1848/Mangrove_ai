# 按角色的新手引导

## 范围与角色

复用现有普通用户、管理员、超级管理员及页面内权限判断。引导不是授权来源，不增加后台接口或访问权限。

| 范围 | 独立流程 | 角色 |
| --- | --- | --- |
| 概览 | 任务概况、服务状态、创建入口 | 全部 |
| 工作台 | 新任务；已有任务的记录、用量与追问 | 全部 |
| 自动化 | 定时计划；运行记录 | 全部 |
| 模板库 | 模板；教训；巡检报告 | 前两项全部，巡检管理员以上 |
| 记忆 | 我的记忆；全局记忆 | 全部，全局修改步骤仅管理员以上 |
| 设置 | 我的设置；模型与连接；采集账号 | 全部 |
| 平台设置 | 平台配置；扩展工具管理；运行与诊断 | 管理员以上 |
| 运营审计 | 总览；登录；访问；操作审计；用户洞察；Token用量 | 管理员以上，说明各自数据范围 |
| 反馈管理 | 查看、审计原任务、点踩处理、导出 | 管理员以上 |
| 用户管理 | 查询、创建、审批、启停；角色调整说明 | 管理员以上，角色调整说明仅超级管理员 |
| 兼容入口 | 历史对话 | 全部 |

## 实现约定

- 已安装的React Joyride 3.2.0提供定位、遮罩、滚动、焦点陷阱；不引入新依赖。具体API以安装版本及官方Props文档为准：https://react-joyride.com/docs/props 。
- `components/onboarding/guides.ts`维护分模块配置；`PageGuide.tsx`负责触发、角色过滤、重播和进度。页面在自己的操作区接入，子页使用独立key。
- localStorage key为`onboarding_v1_`加JSON编码的`[userId, role, pageKey]`，值为`completed`或`skipped`。全局跳过使用`onboarding_all_`加`[userId, role]`。只记录进度，不记录业务内容或凭证。
- 本机同源浏览器内持久化；换浏览器、清理站点存储后会重新引导，不承诺跨设备同步。存储写入失败时仅内存保留并提示。
- 首次页面稳定且没有其他弹窗、用户未输入时自动播放。完成、跳过本页或Esc均不再自动打扰；跳过全部抑制当前用户当前角色所有自动引导，手动重播始终保留。
- 切换页面、子功能或身份卸载旧引导；角色相关步骤二次过滤，隐藏或不存在的目标不展示，不自动打开业务弹窗或触发真实操作。
- 引导期间遮罩及高亮目标均阻止点击，键盘焦点留在气泡；左右方向键切换，Esc退出，关闭后回到教程按钮。保留减少动画偏好、主题和窄屏适配。
- 模型连接原有手动配置引导保留，通用引导不在另一个弹窗/引导打开时启动。

## 验证范围

用户确认在页面交互层使用模拟账号/API验证，不操作真实任务。测试源码`frontend/e2e/onboarding.spec.ts`覆盖首次播放、完成持久化、重播、逐页/全局跳过、用户角色隔离、权限拒绝、存储失败、键盘焦点、窄屏和可访问性。工程验证不等于真实用户验收。

收尾仅对比本轮开工源码副本；不检查或覆盖此前未提交功能。无数据库迁移、后端重启、外部依赖安装、提交或推送。

## 验证结果与维护

- 类型检查与生产构建通过；构建仍提示现有大包，不在本轮拆包。
- 实际8088构建31项隔离API浏览器检查通过，包含慢接口完整步骤、首次失败恢复、输入失焦、业务弹窗让位、同页身份降权、运行任务零业务写入。桌面与390px深色截图已检查，教程气泡axe检查通过。
- Standards/Spec审查发现的异步假完成与输入失焦不重试已修并留回归。没有执行真实任务或修改真实用户数据；用户验收仍待进行。
- 维护时在`guides.ts`追加页面配置，并在页面操作区接入`PageGuide`；依赖异步内容的页面传`ready`或添加`data-guide-loading`标记。不要让接口失败时把缺失的重要步骤记为完成。
- 业务测试若不验证引导，应仅在自己的模拟账号夹具写入`onboarding_all_`加`JSON.stringify([userId, role])`为`skipped`，或正常点击跳过；引导专项测试保持全新存储。勿关闭生产自动触发，也勿读取真实日志代替合成验证。

最短验收：用目标角色进入各页面观察首次播放，完成后刷新确认不再出现；点“新手教程”重播。依次验证跳过本页、跳过全部、键盘操作及不同账号/角色；当前实现按本机浏览器保存，不跨设备同步。
