用户已确认五 Tab 原型、管理员权限范围、隔离验证，以及本机暂停、备份迁移和恢复服务。
不包含 Git 提交、推送、发布、真实模型或邮件操作。

## 验收边界

- 运营总览、登录与活跃、访问与使用、操作审计、用户洞察共用时间与筛选口径。
- 管理员只看普通用户和本人；超管看全平台。列表、统计、用户选择、详情、时间线、导出同一授权。
- 不保存业务正文、密码、Cookie、密钥、原始 URL 或原始请求/响应。IP 掩码、设备仅分类，不调用外部地理服务。
- 从启用时采集，不把历史未采集数据补成零事实；在线状态按前台心跳估计，不能用 Cookie 有效期冒充在线时长。
- 关键变更先登记请求，再登记最终结果；缺少结果显示未知。日志不可通过业务接口编辑；查看/导出留痕。
- 配置差异只记白名单低敏字段，敏感字段只记修改事实，不记录掩码尾号或 SecretRef。
- 导出 CSV / XLSX 有条数限制和注入防护；常用视图按用户保存；保留设置仅超管，默认 180 天，可选 90 天。
- 保留策略仅作用于新增运营日志；既有安全审计仍遵循 ADR-0037。不得删除原业务表和历史绑定。

2. 登录、页面访问、心跳、关键写操作接入，验证失败、未知、去重和查询口径。
3. 按已确认原型接正式页面，验证五 Tab、筛选、详情、导出、错误恢复与窄屏。
4. Standards / Spec 分别审查本轮相对回退副本的改动，不把此前未提交改动当成本轮变更。
5. 隔离库及真实库副本前向迁移、重放、业务数据不变、备份恢复验证通过后，才迁移原库并恢复服务。
