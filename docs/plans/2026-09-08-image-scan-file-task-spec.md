# #131 图片与扫描件统一文件任务

状态：实施中；基线 `d380486b6ebbf9e005529797adb2c07a2b14fdac`。上游 #127、#129 已完成，当前状态以 `docs/status/current.md` 为准。

## 目标与输入

把 PNG、JPEG（含 JPG）、WEBP 静态图片和扫描 PDF 接入既有文件任务、文档工具授权与原件预览。允许输入为当前 Owner 已上传且冻结 SHA256 的原件。OCR 使用既有完整解析服务；RapidOCR 仅负责候选发现，不升级为权威证据。音视频、动画及新增依赖不在本票。

## 输出与交互

- 图片归文档类附件，复用对话输入、自动侧栏、原件下载与缩放/滚动恢复。上传取消或移除后，迟到回包不得恢复附件。
- 原件 API 先核 Owner、任务版本、来源成员与 SHA256，再返回图片原件身份、编码像素宽高及 EXIF 方向。预览不隐式启动 OCR。
- 原件完整不表示文字已识别；解析结果仍是派生内容，正式交付须通过已有覆盖和 QA 门。
- 图片在既有文档 Grant 中表示单个稳定内容单元 `page:1`，复用发现、精读、取消、缓存与覆盖账本，不能绕开授权读取宿主路径。

## 安全与质量边界

- 上传字节继续采用既有配置；图片限静态单帧、1600 万像素，验证容器与实际解码后登记类型，原件不重编码。
- PDF 限 1 至 1000 页，每页按 200 DPI 计算不超过 1600 万像素；更高 DPI 渲染还检查实际分配大小。损坏、加密和超限应明确拒绝，不能靠尝试分配大位图判定。
- 缺失、非法或非有限 OCR 分数记录为未知。内部零值仅用于质量门失败关闭，`confidence_known=false` 不代表识别服务测得 0%。已知有效分数保留。
- 未知置信不得通过权威读取门；保留既有已知分数的页级中位数语义，不将页级可读等同于每个字段已核实。
- 无已核 EXIF/服务转向映射的图片只保留页定位与待复核内容，不把旋转后的坐标画到原件上。表格区域定位不等于单元格级定位。
- 服务坐标认可与识别置信分开：MinerU 仅认可响应明确为 pipeline 3.4.4 的单页模型输出和已核旧版表格区域路径；页面标识、尺寸和坐标须合法，未核回退不得继承认可。Paddle 请求关闭方向分类和去畸变，响应每页仍须明确未启用文档预处理。两者图片消费端都要求 EXIF=1。
- 文档执行器在共用证据生成处拒绝待复核或低于 0.90 的选中元素，全文提取、比较和审查等路径均不能绕过该门。
- 同步远端请求的取消不等于杀掉远端推理；取消后必须丢弃迟到返回并阻止继续写缓存、账本和候选。

MinerU 坐标依据限定为官方 `mineru-3.4.4-released`：图片的 [EXIF 转正与 PDF 转换](https://github.com/opendatalab/MinerU/blob/mineru-3.4.4-released/mineru/utils/pdf_image_tools.py)、[模型页面尺寸绑定](https://github.com/opendatalab/MinerU/blob/mineru-3.4.4-released/mineru/backend/pipeline/model_json_to_middle_json.py)、[表格区域归一化](https://github.com/opendatalab/MinerU/blob/mineru-3.4.4-released/mineru/backend/pipeline/pipeline_middle_json_mkcontent.py)。该范围不代表其他服务版本已通过原件坐标验收。

## 验收

1. 固定合成原生文字、扫描 PDF、图片、旋转及低质量样本从上传至结果可核对，原件 SHA256 不变。
2. 损坏、加密、伪装、超限、跨 Owner、非冻结来源和哈希漂移拒绝；取消与迟到回包有永久回归。
3. 图片与 PDF 原件在桌面/手机可查看、缩放、恢复；失败保留需求与其他附件，识别内容与原件明确区分。
4. 真实 OCR 证据与替身合同证据分别记录；服务健康不能充当识别验收。仅证实已声明的格式与样本范围。
5. 独立 Standards/Spec 审查、最终提交 CI 与浏览器门均通过后，才按既有授权合并并关闭工单。
