# #128 连续对话与 Session 用量任务单

## 目标

在统一工作台展示可恢复的真实公开回答；工作记录默认折叠，确认与恢复操作保持可见。修订、用户和 Session 切换不串内容，未知用量不显示为零，追问保持用户冻结的模型连接。

## 允许输入

#128 工单与已完成的 #127、#118；ADR-0027、ADR-0035；现有 ConversationSteering、SteeringResult、StructuredProgressEvent、WorkTraceProjection、ProviderUsage、ModelConnection Broker 和工作台组件。验证使用合成数据、隔离数据库与受控 Provider 替身；新增依赖另行确认。

## 要求输出

- 复用持久 SteeringResult 的公开回答实时快照；稳定消息身份，重连或刷新后恢复。禁止从内部工具日志、CoreMind text_delta 或 Pi 内部总结拼接正文，也不制造逐字动画。
- 事件归属绑定实际 TaskRevision 与 Run；客户端身份切换后拒绝迟到回调。重连只读取，不触发执行或重复计量。
- 可展开的真实工作记录、醒目的用户待办、停止请求与执行收口区别；上翻保持阅读位置并可回到最新。
- Session 时间与耗时、冻结模型连接、逐项原生 Token 用量。未知显示未知；部分已知只能显示已知下限。没有精确官方价格和核验日期时不提供参考费用。
- 追问复用冻结连接与现有计量边界；不能静默切换 Provider、连接或模型。

## 验收标准

中文跨网络块、Markdown 未闭合、重复和迟到事件、断线和服务重新建立后的持久回放；两个 Owner、两个修订切换隔离；取消与重连无重跑或重记账。覆盖缺失及部分未知用量、BYOK 连接选择和秘密不外露。前端覆盖空态、失败、部分成功、登录待办、键盘、窄屏、明暗、减少动画和受控读屏播报。Standards 与 Spec 两轴复核，同提交最低 CI 和受影响后端及完整浏览器重门通过。

## 边界

复用当前消息和账本存储，不复制执行系统。不开放原始思维链、系统 Prompt、Cookie、密钥、宿主路径或未经确认的远程资源自动加载。不修改 CoreMind 专属 checkout、生产库和秘密，不新建 worktree，不重启已有产品服务或原型。正式交付仍只认通过验证的 output_id。工程、替身浏览器、真实服务、用户视觉认可和发布资格分别记录。

所有本票前端关联实现、验证与审查使用 GPT-6-Astra high；实际会话档位另行核验。本任务单不表示工程已经完成。

## 接缝与验证约定

公开回答复用不可变 SteeringResult：message_id 等于 result_id，version 为 1，GET 与 SSE 使用同一公开投影。正文实际完成时实时到达；本票不提供逐 Token 模型输出。重连采用持久事实重放和稳定 ID 去重，不宣称服务器实现了精确 Last-Event-ID 游标续传。

追问沿用已选连接的 Broker，使用既有 Grant 的确定性调用身份在网络发送前持久占位。同一用户、任务、修订与回合重入时先查已有结果；已有占位但结果未知时失败关闭，不自动重新发起收费请求。通过并发与占位后重建实例回归证明，不创建第二套账本或数据库迁移。

原生用量每个维度分别保留完整性：任一调用该维度缺失时，汇总不可作为精确值显示。总 Token 可展示已知下限和未知调用数；输入、输出与缓存缺失不靠其他字段推算。
