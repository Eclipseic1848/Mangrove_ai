# 分用户 Token 用量与参考成本

## 统计口径

- 仅聚合 `model_provider_usage` 已保存的调用记录，每条记录独立计数；不叠加任务或消息上的累计 Token，避免重复计算。
- 只按带时区的记录进行北京时间日期筛选，起日包含、结束日下一天零点不包含。没有时区的旧记录不猜测归属，不回填。
- 用户是调用记录的 Owner，不是当前查看者。超级管理员查看所有用户（含无法关联现有账号的历史Owner，标为已删除用户）；管理员只查看当前普通用户及本人，与运营用户元数据范围一致。接口每次重新读取角色，普通用户拒绝访问。
- 输入、输出和总量缺失保留未知；有记录的部分仍显示，同时标出未记录完整用量的请求数。成本只累加可估价部分，并显示已估价请求数，不能视为完整账单。
- 本地及平台托管私有模型仅统计请求和Token，显示“无需计价”，不进入云端估价覆盖率或费用合计。导出包含本地请求数；同型号本地和云端调用在明细中分开，历史记录不删除。
- 型号、接口、服务地址来自对应冻结授权，连接后来更换型号不改写历史归属。响应不返回服务地址、密钥、业务正文或原始供应商日志。

## 接口

- `POST /api/operations/tokens/query`：`start`、`end` 必填；支持 `search`、`model`、`api_format`、`currency`、`sort`、`direction`、`page`、`page_size`。
- `POST /api/operations/tokens/export`：`{filters, format: "csv" | "xlsx"}`，导出同一筛选范围的全部用户，不只当前页。
- 页大小为10、20、50、100，默认10。排序支持总Token、参考成本、请求次数及最后使用时间；未知成本排在最后。
- 查询和导出复用既有访问审计包装，记录访问与结果，不保存搜索原文。
- 初版不新增数据库表或索引，无Schema迁移。SQL先聚合，最多10000个用户/模型/接口/输入量分组，SQL执行超过5秒中止并提示缩小范围。达到规模限制时再评估显式索引迁移或预聚合，不静默截断统计。

## 价格配置

默认文件：`src/operations_prices.json`。可用环境变量 `MANGROVE_TOKEN_PRICES_FILE` 指定管理员维护的UTF-8 JSON文件；不通过用户查询参数指定路径。

配置包含版本、每百万Token的输入/输出单价、币种、官方来源、服务域名及允许路径。配置文件每次查询读取，更新后不需重启；应先验证新文件，再原子替换，保留旧副本便于回退。

成本公式：`(输入Token × 输入单价 + 输出Token × 输出单价) / 1,000,000`。计算用Decimal，显示六位小数。

- 按型号、HTTPS官方域名和基础路径匹配；第三方转发、本地模型及未匹配型号不自动套价。
- 计价范围以 `src/model_connections/catalog.py` 的平台目录为准；配置中目录外的型号不展示、不估价。默认配置官网中国区人民币原价：DeepSeek两款、Qwen两款、GLM三款；其他型号无适用中国区报价时保持未估价，不套用国际或旧型号报价。
- 人民币估算不通过美元换算。美元显示才使用 `1 USD = 7 CNY` **示例汇率，非实时市场汇率**，不代表官方美元账单。管理员应按运营口径修改并保留说明。
- Qwen北京共享入口及目录内北京业务空间入口使用北京价；新加坡入口、伪造域名后缀均不套价。GLM仅匹配中国站按量API路径。Kimi中国官网报价已核实，但当前平台预设为国际站 `api.moonshot.ai`，因此不套用国内价，也不擅自更改连接。
- DeepSeek按高峰、缓存未命中参考价估算，不计算时段及缓存折扣。
- 批量、缓存、税费等特殊费用不在基础估价内；支持范围或型号发生变化时须重新核实适用价格。
- 不同模型别名和已退役型号不模糊匹配；需要时新增已核实的精确型号及适用端点。Claude 3.5等旧型号没有可靠当前报价时保持未估价。
- 页面和导出均说明“参考价格，仅供估算，实际以官方账单为准”。价格配置有误时失败关闭，不回退为免费。

官方来源：

- [DeepSeek中国区价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)
- [Qwen Max北京价格](https://help.aliyun.com/zh/model-studio/qwen3-8-max)、[Qwen Flash北京价格](https://help.aliyun.com/zh/model-studio/qwen3-8-flash)
- [GLM中国站价格](https://docs.bigmodel.cn/cn/guide/start/pricing)
- 完整核验与未配置原因见 [国内报价核验](2026-09-20-china-prices-domestic.md) 和 [国际模型中国区报价缺口](2026-09-20-china-prices-global.md)。核验日期2026-09-20；报价不是账户账单，缓存、峰谷、批量和附加服务仍按上文参考估算边界处理。

## 验证方法

在隔离数据库运行 `tests/test_operations_usage_api.py`，验证权限、汇总、金额、北京时间边界、未知值、排序、分页和导出；再组合运行 `tests/test_operations_api.py` 检查原接口未回归。测试所需JWT密钥仅临时生成，不能读取真实配置。

页面使用 `frontend/e2e/operations-tokens.spec.ts` 拦截全部API，检查默认10条、条数切换、搜索回第一页、模型明细、币种、导出、错误状态和窄屏。配合原 `operations.spec.ts`，类型检查和构建。模拟验证不是正式账单核对，也不代表已部署。
