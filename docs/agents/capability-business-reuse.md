# 扩展工具的任务使用与复用

扩展工具管理负责安装、验证、版本和发布。实际使用发生在工作台任务中：
选用工具，冻结精确版本和制品摘要，随后由运行时按工具声明调用。
仅安装工具或得到正确结果，不能证明任务使用了该工具。

## 在工作台使用

扩展工具的设置、展示和选用仅向超级管理员开放；普通用户和管理员均不可见，
直接访问相关接口也会被拒绝。内置采集、模型配置与普通任务保持原有权限。

超级管理员打开工作台，上传资料并选择输出格式。依次展开输入区的
“输出” → “更多” → “扩展工具（超级管理员）”，勾选已获准工具；具有完整复用声明的工具
也可点击“复用同类工具”，按当前文件、输出和声明操作匹配。
确认匹配结果后创建任务。工具选择随任务版本冻结，创建后不能替换。

`csv-group-summary@1.0.0` 支持 CSV 按列分组求和。例如上传：

```csv
部门,金额
研发,0.1
市场,12.50
研发,0.2
```

选择 JSON 输出，选用工具，并填写：

> 使用选用的分组求和工具，按部门汇总金额。只输出一份 JSON，包含 groups
> 和 row_count；汇总值使用十进制字符串，保留零和负数。

任务初稿仍可由用户选择接受或继续核对。验收工具业务能力时，应继续核验，
并确认执行记录出现成功的 `capability_csv_group_summary` 调用、结果正确和正式交付。
其余同类任务可复用同一工具。当前匹配依据声明的操作及格式；不承诺只输入自然语言
便自动发现并调用所有工具。

## 新增工具

参考 `examples/capabilities/csv-group-summary/`：

1. 提供可独立运行的入口、参数校验、健康检查和明确权限。
2. 用 `mangrove-capability.json` 声明运行入口；用 `reuse-contract.json` 声明
   操作、输入/输出格式和参数结构，同时提供许可证与公共来源。
3. 以新版本登记 OCI 制品摘要。将复用契约 JSON 写入目录 manifest 的
   `reuse_contract`，不改写已有版本制品。
4. 从个人草稿开始，用实际调用工具并形成正式输出的本人任务执行验证；
   通过五步验证及供应链检查后晋级。
5. 平台发布须生成脱敏快照，完成六步验证与签名，再发布至获准受众。
   存储受众仍为 `admin_gray`；产品入口另要求超级管理员，不向管理员或普通用户开放。

任务运行时读取冻结用途和参数说明；平台复用契约来自精确签名制品。
缺少声明、格式不兼容、摘要变化、撤销或隔离仍由既有门拒绝。

## 验证入口

```bash
python examples/capabilities/csv-group-summary/table_summary.py --health
python -m pytest -q tests/test_csv_group_summary_capability.py tests/test_capability_host.py
```

`scripts/verify_capability_business_reuse.py --help` 提供隔离业务验证入口。
该脚本使用现有模型配置，创建新隔离数据库，验证两个样本的匹配、实际工具调用、
汇总结果和完整核验；不发布平台工具。真实模型调用会消耗 Token。
