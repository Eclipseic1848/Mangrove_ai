# 问题分诊标签

工程技能使用五个固定角色。当前角色与 GitHub 标签一一对应：

| 工程技能角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者判断问题性质和优先级 |
| `needs-info` | `needs-info` | 等待报告者补充必要信息 |
| `ready-for-agent` | `ready-for-agent` | 需求已明确，可交给 Agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工判断或实施 |
| `wontfix` | `wontfix` | 已决定不处理 |

工程技能提到某个分诊角色时，应使用表中对应的 GitHub 标签。若仓库以后更换标签命名，
只修改右侧映射，不改变技能所使用的角色含义。

本文件只定义标签词汇，不代表这些标签已经在 GitHub 远端创建。
