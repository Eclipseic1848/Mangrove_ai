# 技能：社交媒体采集（抖音 / 小红书 / 微博 / B站 / 快手）

## 策略
- 这些平台有强签名风控，通用引擎（crawl4ai/scrapling/浏览器）多数拿不到评论数据。
- 已接入 **MediaCrawler** 专用采集器（tier 0，命中社媒平台优先使用）解决签名问题，
  免登录优先，必要时注入 cookie；VOC/评论类任务会自动请求抓取评论。

## 合规注意（重要）
- MediaCrawler 为「非商业学习使用许可证」，禁止商用与大规模采集。
- 商业化前需替换为合规方案（官方 API / 商业数据源 / MediaCrawlerPro 授权）。
- 控速、遵守平台服务条款与 robots，避免对平台造成运营干扰。

## 当前行为
- 支持平台：抖音 dy / 小红书 xhs / 微博 wb / B站 bili / 快手 ks / 知乎 zhihu / 贴吧 tieba。
- 首次使用某平台通常需按 MediaCrawler 文档完成登录（扫码）/配置 cookie。
- 若平台不在上表（如懂车帝），路由会退化到通用引擎/搜索页兜底，数据质量有限，请在回复中说明。
